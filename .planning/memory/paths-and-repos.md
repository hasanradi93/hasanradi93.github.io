name: paths-and-repos
description: Which repository serves which path under hasanradi93.github.io
---

- `/` comes from this repo (`hasanradi93.github.io`).
- `/datapilot/` comes from the public repo `hasanradi93/datapilot`, a GitHub Pages project site.
- `/sqlnext/` will come from `hasanradi93/sqlnext` once the owner publishes it.
- `/schemazone/` is a build copied into this repo from the private `hasanradi93/schemazone`.

**Why:** GitHub serves project repos under the user site's domain. A folder of the same name in this repo would clash with that repo's page.

**How to apply:**
- Never create `datapilot/` or `sqlnext/` folders here.
- Never create a public repo named `schemazone`.
